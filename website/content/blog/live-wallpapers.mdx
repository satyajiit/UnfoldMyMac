Pulse turns system load into a moving chrome sculpture. Codex Mission Control gives coding activity a small robot. GitHub After Hours turns a public profile into a floating city. Each is a scene in UnfoldMyMac’s wallpaper library, with a visual template and optional data behind it.

The app includes ten wallpaper scenes. You can try a preview before choosing **Use wallpaper**, and you can leave the personal data connections alone until you want them. The [project overview](https://github.com/satyajiit/UnfoldMyMac#living-wallpapers) describes the collection.

## Start with the scene

Choose a wallpaper for what you want to look at. Daydream brings in an image and floating glass. Lights Out has an open-wheel car, a flowing circuit, and a five-light countdown. Grok Event Horizon puts a black hole on your desktop.

GTA VI — Vice City Countdown puts official Rockstar artwork behind the wait. It counts calendar days in your time zone toward the console release date stored in the template. [Rockstar currently lists November 19, 2026](https://www.rockstargames.com/VI), checked September 12, 2026. The artwork is © Rockstar Games.

Aurora Observatory takes the view into orbit. Public [NOAA OVATION forecasts](https://www.swpc.noaa.gov/products/aurora-30-minute-forecast) shape the auroral curtains, while planetary Kp readings give the scene its activity level. The globe uses [NASA Earth Observatory imagery](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/). It is an artistic interpretation of space weather, with no account setup required.

The Grok and racing counters are wallpaper-session counters. They do not report Grok service usage or live race telemetry. The website’s wallpaper recordings also use sample data, so their numbers are demonstrations, not measurements of your machine.

## Add data when it serves the scene

Some scenes can react to Mac metrics, such as CPU load, memory estimates, and battery information. Others can use local Claude or Codex metadata or a public GitHub profile.

The visual template and data provider are separate pieces. That lets the renderer use a snapshot without needing to know how the data was collected. It also gives contributors a way to add a provider or a scene without replacing the wallpaper engine. The [extension guide](https://github.com/satyajiit/UnfoldMyMac/blob/main/MacDuo/DEVELOPING.md) explains the native architecture.

## Set playback for your Mac

Wallpapers support 30 or 60 fps playback across displays. The playback policy lowers the maximum to 30 fps under low-power or thermal limits. Sleep stops playback. Reduce Motion disables continuous animation and limits updates.

These are the app’s playback rules, not a promise that every GPU and display combination will sustain the same frame rate. The policy is visible in [WallpaperPlayback.swift](https://github.com/satyajiit/UnfoldMyMac/blob/main/MacDuo/Sources/UnfoldMyMacCore/Wallpaper/WallpaperPlayback.swift).

## Bring your own picture or snapshot

Scenes that support custom backgrounds let you import an image; GTA VI and Aurora Observatory keep their bundled artwork. You can also connect local JSON/JSONL data. Start with the built-in scenes to learn what the library already supports, then change the input that matters to you.

The app stores its own copy of imported artwork, so moving the original does not break the design. Optional connections live in **Data & settings**. The [data connection guide](/blog/connecting-your-data/) covers what each source reads and which ones use the network.
